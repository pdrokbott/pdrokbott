## 🇧🇷 Sobre mim · 🇺🇸 About me

> **PT** — Sou **Full Stack Developer** e **pecuarista**. Essa combinação me deu algo raro em dev: eu sinto o problema na pele antes de escrever a primeira linha. Por isso **fecho os requisitos antes de arquitetar** — código bonito que resolve o problema errado não vale nada. Lanço produtos de ponta a ponta: do banco de dados ao PWA que roda offline no meio do pasto.

> **EN** — I'm a **Full Stack Developer** and a **cattle rancher**. That mix gave me something rare among devs: I live the problem before I write the first line. So I **lock the requirements before I architect** — elegant code that solves the wrong problem is worthless. I ship products end to end: from the database to a PWA that runs offline in the middle of a field.

🧠 *Filosofia / Philosophy:* **Requisitos → Arquitetura → Código.** Sempre nessa ordem.
